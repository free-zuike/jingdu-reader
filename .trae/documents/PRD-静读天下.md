# 静读天下Web端 - 产品需求文档

## 1. 产品概述

静读天下是一个基于Cloudflare Workers的在线阅读平台，旨在为用户提供便捷的电子书阅读体验。通过连接WebDAV数据源，用户可以将自己的电子书库同步到云端，随时随地通过浏览器阅读。

- **核心目的**：解决用户在不同设备间阅读书籍的需求，通过WebDAV统一管理书籍，实现跨平台在线阅读
- **目标用户**：拥有个人电子书库的用户，需要在多个设备间同步阅读进度的读者
- **产品价值**：轻量级、无需自建服务器、低成本维护的私人阅读解决方案

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 普通用户 | 邮箱注册/登录 | 管理个人书籍库、在线阅读、设置阅读偏好 |

### 2.2 功能模块

1. **用户认证模块**：邮箱注册、登录、登出、会话管理
2. **WebDAV连接模块**：配置WebDAV服务器、同步书籍列表
3. **书籍管理模块**：书籍列表、书籍详情、阅读进度跟踪
4. **在线阅读模块**：书籍阅读器、翻页功能、阅读设置
5. **用户设置模块**：个人资料、WebDAV配置、阅读偏好设置

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 登录页 | 登录表单 | 邮箱密码登录、注册链接 |
| 注册页 | 注册表单 | 邮箱验证码注册、密码设置 |
| 首页 | 书籍列表 | 展示已同步的书籍、支持搜索筛选 |
| 阅读页 | 阅读器 | 书籍内容展示、翻页控制、阅读设置 |
| 设置页 | 配置面板 | WebDAV配置、个人信息管理 |

## 3. 核心流程

### 3.1 用户注册登录流程

```
用户 → 输入邮箱 → 获取验证码 → 设置密码 → 注册成功 → 自动登录 → 进入首页
用户 → 输入邮箱密码 → 验证成功 → 获取会话Token → 进入首页
```

### 3.2 书籍同步流程

```
用户配置WebDAV → 系统连接WebDAV服务器 → 获取书籍文件列表 → 解析元数据 → 存储到KV → 展示书籍列表
```

### 3.3 阅读流程

```
选择书籍 → 加载书籍内容 → 展示阅读界面 → 用户翻页 → 保存阅读进度 → 继续阅读
```

## 4. 用户界面设计

### 4.1 设计风格

- **设计理念**：简洁优雅的阅读体验，专注于内容呈现
- **配色方案**：
  - 主色：#1a1a2e（深蓝黑色）用于背景
  - 次要色：#16213e（深蓝色）用于卡片
  - 强调色：#e94560（玫红色）用于交互元素
  - 文字色：#eaeaea（浅灰色）用于正文
  - 辅助色：#0f3460（蓝色）用于按钮
- **字体选择**：
  - 标题：思源宋体（Noto Serif SC）- 典雅书卷气
  - 正文：思源黑体（Noto Sans SC）- 清晰易读
- **布局风格**：卡片式布局、顶部导航栏、侧边栏可选
- **图标风格**：简洁线性图标、适中大小

### 4.2 页面设计概览

#### 登录页
- 居中卡片式表单
- 邮箱输入框、密码输入框、登录按钮
- 底部注册链接
- 背景渐变效果

#### 注册页
- 居中卡片式表单
- 邮箱输入框、验证码输入框、密码输入框、确认密码输入框
- 获取验证码按钮、注册按钮
- 底部登录链接

#### 首页（书籍列表）
- 顶部搜索栏和用户菜单
- 书籍网格/列表展示
- 每本书显示封面、标题、作者、阅读进度
- FAB按钮用于刷新同步

#### 阅读页
- 全屏阅读区域
- 顶部导航栏（返回、设置、目录）
- 底部翻页控制条
- 左右滑动翻页支持
- 护眼背景模式可选

#### 设置页
- 分组设置面板
- WebDAV配置表单
- 阅读偏好设置
- 个人信息管理
- 登出按钮

### 4.3 响应式设计

- **桌面优先设计**：适配1920px、1440px、1280px屏幕
- **平板适配**：1024px、768px布局调整
- **移动端适配**：375px以上触摸优化
- **触摸优化**：大触摸目标、滑动翻页、手势支持

## 5. 技术约束

- 使用Cloudflare Workers作为后端服务
- 使用KV命名空间存储用户数据和书籍信息
- 支持主流电子书格式：EPUB、TXT、PDF（优先支持EPUB和TXT）
- 所有数据传输使用HTTPS加密
- 会话Token使用JWT格式，过期时间24小时
