### 1.2 技术栈

- **前端框架**：原生HTML5 + CSS3 + JavaScript ES6+
- **后端服务**：Cloudflare Workers (JavaScript/TypeScript)
- **数据存储**：
  - Cloudflare KV（会话、阅读进度、缓存）
  - Cloudflare D1（用户数据、配置）
  - Cloudflare R2（书籍文件临时存储）
- **构建工具**：Wrangler CLI
- **邮件服务**：Cloudflare Email Routing / 第三方SMTP

## 3. 路由定义

### 3.1 前端路由

| 路由 | 页面 | 功能 |
|------|------|------|
| `/` | index.html | 登录页 |
| `/register` | register.html | 注册页 |
| `/home` | home.html | 书籍列表首页 |
| `/reader/:bookId` | reader.html | 书籍阅读器 |

### 3.2 API路由

| API路由 | 方法 | 功能 |
|---------|------|------|
| `/api/auth/register` | POST | 用户注册 |
| `/api/auth/login` | POST | 用户登录 |
| `/api/auth/logout` | POST | 用户登出 |
| `/api/auth/verify-code` | POST | 发送验证码 |
| `/api/user/profile` | GET | 获取用户信息 |
| `/api/user/profile` | PUT | 更新用户信息 |
| `/api/user/webdav` | GET | 获取WebDAV配置 |
| `/api/user/webdav` | PUT | 更新WebDAV配置 |
| `/api/books` | GET | 获取书籍列表 |
| `/api/books/:id` | GET | 获取书籍详情 |
| `/api/books/:id/content` | GET | 获取书籍内容 |
| `/api/books/:id/progress` | GET | 获取阅读进度 |
| `/api/books/:id/progress` | PUT | 更新阅读进度 |

```typescript
  email: string;

{
  success: boolean;
  data: {
```

#### 登录


## 5. 数据库设计

### 5.1 D1数据库Schema

```sql
-- 用户表
CREATE TABLE users (
  id TEXT PRIMARY KEY,
  email TEXT UNIQUE NOT NULL,
  password_hash TEXT NOT NULL,
  created_at TEXT DEFAULT (datetime('now')),
  updated_at TEXT DEFAULT (datetime('now'))
);

-- WebDAV配置表
CREATE TABLE webdav_configs (
  id TEXT PRIMARY KEY,
  user_id TEXT NOT NULL,
  server_url TEXT NOT NULL,
  username TEXT NOT NULL,
  password_encrypted TEXT NOT NULL,
  base_path TEXT DEFAULT '/',
  created_at TEXT DEFAULT (datetime('now')),
  updated_at TEXT DEFAULT (datetime('now')),
  FOREIGN KEY (user_id) REFERENCES users(id)
);

-- 邮箱验证码表
CREATE TABLE email_verification (
  id TEXT PRIMARY KEY,
  email TEXT NOT NULL,
  code TEXT NOT NULL,
  type TEXT NOT NULL,
  expires_at TEXT NOT NULL,
  created_at TEXT DEFAULT (datetime('now'))
);
```

### 5.2 KV存储结构

```typescript
// 会话存储
KV_KEYS: {
  "session:{token}": {
    userId: string;
    email: string;
    expiresAt: number;
  }
}

// 阅读进度
KV_KEYS: {
  "progress:{userId}:{bookId}": {
    currentPosition: number;
    totalLength: number;
    lastReadAt: number;
  }
}

// 书籍元数据缓存
KV_KEYS: {
  "book:{bookId}": {
    id: string;
    title: string;
    author: string;
    cover?: string;
    format: string;
    chapters: Array<{title, startIndex, endIndex}>;
    content?: string; // 缓存的完整内容
    cachedAt: number;
  }
}
```

## 6. 安全考虑

### 6.1 认证安全

- 密码使用bcrypt加密存储（cost factor: 10）
- JWT Token过期时间：24小时
- 邮箱验证码：6位数字，5分钟有效期，每个邮箱每分钟限发1次
- 敏感操作需要重新验证

### 6.2 数据安全

- WebDAV密码加密存储（使用AES-256-GCM）
- 所有API使用HTTPS传输
- CORS配置限制允许的来源
- 输入验证和SQL注入防护

### 6.3 API安全

- 频率限制：每个IP每分钟100请求
- 请求大小限制：1MB
- 错误信息不暴露敏感细节

## 7. 性能优化

### 7.1 边缘计算

- 使用Cloudflare Workers在边缘节点执行
- 减少网络延迟，提高响应速度

### 7.2 缓存策略

- 书籍内容缓存在KV中，设置TTL为1小时
- 静态资源使用Cache-Control
- ETag支持条件请求

### 7.3 懒加载

- 书籍列表分页加载
- 书籍内容按需获取
- 图片延迟加载
